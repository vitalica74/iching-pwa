# Книга Змін — I Ching PWA

**Версія 1.0.0**

Офлайн-застосунок для роботи з «Книгою Змін» за класичним методом трьох монет. Мета застосунку — не просто показати номер гексаграми, а провести читання як послідовність:

**Поточний стан → Точки зміни → Напрямок розвитку**

Жива версія: https://vitalica74.github.io/iching-pwa/

## Що вміє застосунок

- класичне жеребкування трьома монетами;
- шість ліній будуються знизу вгору;
- визначення початкової та результуючої гексаграм;
- практичне читання ситуації простою сучасною мовою;
- окремі трактування змінних ліній;
- «роздоріжжя» — кілька можливих напрямків дії без нав'язування одного сценарію;
- класичні ракурси Ріхарда Вільгельма та Юліана Шуцького як стислі авторські українські перекази, а не дослівні цитати;
- цикл кожної гексаграми як карта внутрішнього розвитку її шести позицій;
- Бібліотека для перегляду всіх 64 гексаграм без жеребкування;
- таблиця верхніх і нижніх триграм для вибору гексаграми;
- перегляд усіх шести ліній у Бібліотеці та моделювання окремої зміни;
- історія звернень в IndexedDB;
- збереження точного знімка отриманої інтерпретації;
- експорт та імпорт історії у JSON;
- робота офлайн після першого відкриття;
- встановлення як PWA на телефон або комп'ютер.

## Модель читання

### 1. Поточний стан

Початкова гексаграма описує структуру ситуації: що відбувається зараз, яка якість переважає і на що варто звернути увагу.

### 2. Точки зміни

Змінні лінії показують не окремі передбачення, а активні місця поточного стану. Кожна лінія має власну назву, стадію, сучасне пояснення та практичну пораду.

Якщо змінних ліній кілька, вони розглядаються разом як кілька рухомих частин однієї ситуації.

### 3. Напрямок розвитку

Результуюча гексаграма не трактується як гарантоване майбутнє. Вона показує нову якість ситуації, що виникає через зміну активних ліній.

Таким чином застосунок не намагається сказати «що обов'язково станеться», а допомагає побачити стан, зміну та можливий напрямок.

## Роздоріжжя

Практична рекомендація навмисно не зводиться до одного наказу. Для ситуації можуть бути показані кілька доречних шляхів із коротким поясненням наслідків кожного.

Це дає користувачу напрямок для рішення, але залишає вибір за ним.

## Практичний і класичний режими

Є два способи читання:

- **Практичний** — спочатку коротка сучасна рекомендація;
- **Класичний** — спочатку трактування Вільгельма та Шуцького.

Режим змінює порядок читання, а не саму структуру жеребкування.

## Бібліотека

Режим **Бібліотека** дозволяє досліджувати «Книгу Змін» без випадкового жеребкування.

Гексаграму можна вибрати через таблицю верхніх і нижніх триграм. Для кожної гексаграми доступні:

- основне сучасне трактування;
- цикл стану;
- класичні трактування;
- шість змінних ліній;
- класичні трактування окремих ліній;
- перегляд того, до якої гексаграми веде зміна конкретної лінії.

## Історія та довговічність записів

Історія зберігається локально в IndexedDB.

Кожне нове звернення містить:

- точні результати кидків;
- шість побудованих ліній;
- початкову та результуючу гексаграми;
- активні змінні лінії;
- версії застосунку, бібліотеки, рушія та таблиці відповідностей;
- структурований знімок інтерпретації;
- текст, який користувач отримав у момент звернення.

Оновлення бібліотеки не переписує старі записи. За бажанням старе звернення можна окремо переосмислити за поточною бібліотекою.

## Виправлення таблиці Вень-вана

У ранніх тестових версіях ключ відповідності верхньої та нижньої триграм був складений у неправильному порядку. В актуальній версії номер гексаграми визначається як:

**нижня триграма + верхня триграма**.

Старі записи зберігають первинні шість ліній і за потреби перераховуються правильно.

## Архітектура

Основні модулі:

- `data/hexagrams.js` — 64 гексаграми та канонічна таблиця відповідностей;
- `data/changing-lines.js` + пакети `changing-lines-*` — 384 змінні лінії;
- `data/classical-sources.js` — класичні трактування станів;
- `data/classical-lines.js` + пакети `classical-lines-*` — класичні трактування ліній;
- `data/hexagram-cycles.js` + пакети — цикли гексаграм;
- `data/crossroads.js` + пакети — практичні варіанти «роздоріжжя»;
- `js/interpretation.js` — рушій складання інтерпретації;
- `js/reading-ui.js` — додатковий шар представлення читання;
- `js/library.js` — режим Бібліотеки;
- `js/storage.js` — локальна історія та імпорт/експорт;
- `service-worker.js` — офлайн-кеш PWA.

Докладніше про принцип інтерпретації: `docs/INTERPRETATION-MODEL.md`.

## Приватність

Застосунок не потребує серверної бази для історії звернень. Дані користувача зберігаються локально у браузері. Експорт історії виконується вручну у JSON-файл.

## Статус 1.0

Версія 1.0 фіксує першу цілісну публічну модель застосунку. Подальші зміни плануються насамперед на основі реального використання та відгуків користувачів, а не шляхом безкінечного ускладнення інтерфейсу.

## Ліцензія та тексти

Класичні блоки Вільгельма та Шуцького в застосунку є стислими авторськими українськими переказами й не подаються як дослівні цитати з видань або сучасних перекладів.
