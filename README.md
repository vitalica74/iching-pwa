# Книга Змін PWA 3.4

### Важливе виправлення 3.4

У версіях до 3.3 таблиця Вень-вана містила правильні пари, але функція пошуку складала ключ як `upper+lower`, тоді як сама таблиця була записана як `lower+upper`. Через це асиметричні гексаграми отримували номер гексаграми з переставленими триграмами.

Тепер лінії, як і раніше, створюються знизу вгору, а номер визначається як `нижня триграма + верхня триграма`. Додано контрольні перевірки, зокрема №32 (Вітер внизу, Грім вгорі) та №42 (Грім внизу, Вітер вгорі). Старі записи зберігають свої шість ліній і при відкритті перераховуються правильно; старий текст доступний лише як архівний знімок.


Модульна офлайн-PWA для класичного методу трьох монет.

## Архітектура знань
- `data/hexagrams.js` — 64 основні гексаграми.
- `data/changing-lines.js` — розширювана бібліотека 384 змінних ліній.
- `data/transitions.js` — база до 4096 пар переходів; готовий запис має пріоритет.
- `data/profiles.js` — контексти, стилі та авторські збірки.
- `js/interpretation.js` — рушій логічної рекомендації.

## Версія 3.4 — виправлена відповідність гексаграм

Після шостої лінії застосунок спочатку показує одну послідовну відповідь:

1. що відбувається зараз;
2. у чому головна причина;
3. що робити зараз;
4. чого не робити;
5. до чого це веде.

Опис основної гексаграми, змінні лінії, додаткова гексаграма та повний текст переходу не зникли. Вони розміщені в згорнутих розділах під рекомендацією. Стиль змінює форму подачі, але не зміст; контекст лише пояснює ту саму пораду мовою обраної сфери.

## Довговічна історія

Історія зберігається в IndexedDB. Кожний новий запис містить точні результати кидків, версії бібліотеки й рушія, структурований знімок інтерпретації та готовий текст, який користувач прочитав. Старі знімки попередньої структури підтримуються й не переписуються автоматично.


## v3.5 — режими читання

- Залишено лише два режими: Практичний і Класичний.
- Головна відповідь скорочена до: Суть → Що робити → До чого веде.
- Класичний шар винесено окремо: Вільгельм і Шуцький.
- Класичні тексти в цій тестовій збірці є стислими авторськими переказами, не цитатами.
- Перевірений пілотний корпус наразі містить гексаграми 32, 58 і 60; для решти показується чесний статус, що джерело ще не внесено.
- Це дозволяє тестувати UX і порядок читання без вигадування текстів від імені авторів.


## v3.7
- Режим читання відокремлено від збереженого змісту інтерпретації.
- Поточний вибір Практичний/Класичний завжди керує порядком блоків, у тому числі для історичних snapshot.
- У заголовку рекомендації показується активний режим для контролю.

## v3.9
- Поле питання та кнопка створення лінії перенесені вище блоку рекомендації, щоб під час кидків було видно побудову гексаграми.
- Деталі тепер не дублюють коротку відповідь: основна гексаграма не повторює «Що робити»; додаткова показує лише сенс нового стану; перехід пояснює тільки сам перехід і характер зміни.
- Практична/класична схема читання з v3.7 збережена.

### Класичний корпус 1.0
- Додано стислі офлайн-трактування всіх 64 гексаграм за двома окремими ракурсами: Ріхард Вільгельм і Юліан Шуцький.
- Це авторські українські перекази, а не дослівні цитати чи копії сучасних перекладів.
- Джерела та версія корпусу зберігаються в `data/classical-sources.js`.
- Наступний етап — 384 змінні лінії для кожного класичного джерела.


## v4.0 — класичні змінні лінії
Додано окремий модуль `data/classical-lines.js`. Перший звірений пакет містить лінійні трактування Вільгельма та Шуцького для гексаграм №1, 32, 33, 58, 60 і 64 (36 ліній на автора). Для решти ліній застосунок чесно показує, що класичний запис ще доповнюється; шаблонний текст від імені автора не генерується.
