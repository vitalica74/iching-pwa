Спосіб інтерпретації

        
        
        
        
        
        
        
Два режими змінюють лише порядок читання, а не зміст. Практичний шар дає одну синтезовану дію; Вільгельм і Шуцький залишаються окремими класичними ракурсами. Контекст адаптує лише практичну дію.

      

      

        
Про додаток

        
Версія: 4.1.0 PWA

        
Метод: три монети, шість ліній знизу вгору

        
Модель читання: поточний стан → точки зміни → напрямок розвитку

        
Генератор: Web Crypto API + ентропія взаємодії

        
Робота: офлайн після першого відкриття

        
Історія: IndexedDB із точним знімком отриманої інтерпретації
