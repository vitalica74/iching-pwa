# I Ching PWA — interpretation model

## Базова модель читання

Застосунок читає жеребкування як три пов'язані етапи:

**Поточний стан → Точки зміни → Напрямок розвитку**

### 1. Початкова гексаграма — стан

Відповідає на питання: «У якій ситуації я перебуваю?»

Вона описує структуру поточного стану, його головну якість, напруження та природний спосіб дії.

### 2. Змінні лінії — точки зміни

Відповідають на питання: «Що саме в цій ситуації зараз рухається або потребує уваги?»

Кожна змінна лінія має індивідуальні поля:

```js
{
  title: "Коротка назва",
  stage: "Місце в розвитку",
  meaning: "Сучасне пояснення",
  advice: "Практична рекомендація"
}
```

`title` — коротке формулювання головного змісту лінії.

`stage` — структурне місце лінії у розвитку гексаграми.

`meaning` — сучасне пояснення конкретної ситуації.

`advice` — практичний напрямок дії.

Якщо змінних ліній кілька, вони описують кілька активних точок одного стану. Їхні зміни разом формують одну результуючу гексаграму.

Якщо змінних ліній немає, читання залишається на рівні початкової гексаграми.

### 3. Результуюча гексаграма — напрямок

Відповідає на питання: «Яку нову якість набуває ситуація через цю зміну?»

Результуюча гексаграма не є гарантованим майбутнім або винагородою за виконання поради. Вона показує новий стан чи перспективу розвитку, що виникає через зміну активних ліній.

## Цикл гексаграми

Кожна гексаграма може мати `cycle` — коротку карту внутрішнього розвитку її шести позицій.

Приклад:

**помітити → узгодитися → виконати → стриматися → стати опорою → не перейти межу**

Цикл не є додатковою «сьомою стадією» і не замінює результуючу гексаграму. Він допомагає побачити, як змінюється якість усередині самої гексаграми.

## Класичні трактування

`classical-sources.js` і `classical-lines.js` зберігають окремі стислі українські перекази Вільгельма та Шуцького, а не дослівні цитати.

Два автори мають залишатися різними ракурсами:

- **Вільгельм** — образ, життєва ситуація, морально-практичний сенс;
- **Шуцький** — структура, позиція лінії, фаза розвитку та текстологічний контекст.

Практичні `meaning` та `advice` не є механічним середнім між цими авторами. Це сучасне прикладне прочитання, яке спирається на класичний матеріал.

## Перехід між станами

Смисловий міст не слід жорстко записувати як правило «лінія X завжди веде до гексаграми Y», тому що за одночасної зміни кількох ліній результуюча гексаграма буде іншою.

Повне читання переходу складається з:

**початкова гексаграма + активна лінія або лінії + результуюча гексаграма**.

Окремі ручні тексти переходів потрібні лише там, де автоматичне складання втрачає важливий зміст.

## Роздоріжжя

Практична рекомендація може показувати кілька доречних шляхів замість одного наказу. Кожен шлях коротко пояснює, що він означає для цієї ситуації.

Мета — дати напрямок, але не приховувати від користувача, що вибір залишається за ним.

## Принцип інтерфейсу

Інтерфейс має підкреслювати логіку:

**Поточний стан → Точки зміни → Напрямок розвитку**

Деталі відкриваються поступово. Основна відповідь повинна бути зрозумілою без обов'язкового читання всіх класичних і структурних шарів.

## Бібліотека

Режим Бібліотеки використовує ту саму модель знань, але без випадкового жеребкування. Користувач може вибрати гексаграму, дослідити її шість ліній і окремо змоделювати зміну будь-якої лінії.

## Історичні записи

Збережене звернення містить точні лінії та snapshot інтерпретації. Пізніші зміни бібліотеки не повинні мовчки переписувати старий текст. Нове прочитання виконується лише як окрема дія користувача.
